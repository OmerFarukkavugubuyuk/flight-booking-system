# Flight Booking System

A full-stack flight reservation system built around a relational database schema, RESTful API, and vanilla JavaScript SPA front-end.

## Project Structure

- `database/` — SQL schema definitions (`schema.sql`), initial seed data (`seed.sql`), and reference queries (`queries.sql`).
- `backend/` — Server implementation and API endpoints.
- `frontend/` — Static HTML, CSS, and JS single-page application.

## Database Setup

1. Run `database/schema.sql` to create all 10 relational tables and constraints.
2. Run `database/seed.sql` to populate the database with sample data.
